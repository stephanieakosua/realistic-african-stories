# Attribution and origin

Realistic African Stories is a new project and a separate repository. It is conceptually informed by the public GitHub repository [ai-playbooks/realistic-consistent-character-videos](https://github.com/ai-playbooks/realistic-consistent-character-videos), whose public README describes character anchors, reference images, voice locks, image-to-video prompting and clip editing. This project supplies a newly written, independent prompt workflow for African film narratives, multi-character casts, fixed locations and long-form shot lists.
