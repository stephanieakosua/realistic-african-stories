# Guidance for AI assistants

Use `PLAYBOOK.md` as the canonical staged workflow. Start a new session by asking only for the user's story idea or inviting them to request 10 ideas. Do not send a production intake questionnaire. Stop after screenplay Scenes 1 and 2 for user notes. Keep image prompts independently complete, with full location and identity locks and unambiguous clothing-colour speaker identification. Follow all duration, dialogue, character and location constraints.
